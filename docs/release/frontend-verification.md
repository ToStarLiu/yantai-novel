## 修复过的实际问题

- 新作品创建后，旧作品列表刷新之前自动切回旧项目；现保持新选择，等列表更新。
- 采用候选/恢复历史时在新正文版本取回之前重建编辑器，导致基线与画面不一致；现先读取新版本再重建。
- 记忆编辑成功后，本地决定仍是 Pending，之后批量保存会把它误改为 Reject；现同步为 Accept。
- React Suspense 懒加载使 Tiptap 初始命令管理器尚未就绪时执行 setContent；现延迟渲染，初始内容交由编辑器创建流程，只有明确恢复操作才安全重设。
- 移动端助手浮层挡住外部关闭按钮；现浮层内有可访问的关闭按钮。

部分中间浏览器失败来自测试夹具缺少 Origin、缺少章纲、以及两个测试执行器竞争同一输出目录。这些已纠正；最终结果来自单一执行器独占的完整运行，没有把失败检查冒记为通过。

## 高级创作工作室增补

2026-11-12 22:42，完整工作室已接入实际后端接口，入口是作者工作台顶栏的“创作工作室”。它按需加载，保留正文工作台。高级模块不是静态设计稿或本地假按钮：

- React Flow 剧情画布支持拖拽、连线、因果/前置/分支关系、条件与结局、时间与有效期投影；节点生成场景候选、关系解释，作者明确采用后才加入场景序列，保留节点与画布版本来源。
- 三层规划表单覆盖读者承诺、人物冲突与失败代价、卷章结构；全书、分卷和本章规划候选分别采用；规划/场景/人物弧/画布历史可以恢复为新版本。
- 场景导演包含目标、冲突、前因、观察角色、在场角色、位置/物品/动作交接、连续性要求、画布关联；人物弧包含目标、情绪、重要性、近期权重与遗忘投影。
- 隔离参考资料支持文件与文本导入、真实结构统计和文风提炼；显式选择公开 URL 抓取，逐来源显示实际成功或错误；默认未配置搜索服务时明确提示，不伪造联网结果；正文与参考原文重合检查有原文证据。
- 百科按实体显示确认事实、支持与冲突来源、角色信念投影；沙盒回合只产生候选，确认后仅更新沙盒，支持检查点、冻结和回滚；故事分支创建新作品，正文相互独立。
- 批注绑定原正文引文并可解决；协作包括邀请注册/已有账户验证、成员角色、在线位置和持久变更通知；只读/审校账户的正文编辑器不可写，后端同时强制权限。
