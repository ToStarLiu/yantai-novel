# 当前支持范围与已知限制

日期：2026-11-13。本文对应当前工作区候选；代码存在、自动测试通过、真实服务实测和作者质量验收是不同证据，执行记录见交付验收文档。

## 产品与工作方式

- Web 工作台、可安装 PWA 与 Electron 本地客户端已实现；桌面打包和启动的具体执行结果见交付验收记录。代码签名、应用商店发行、外部平台自动投稿不属于当前验证结果。
- 支持作品级成员权限、邀请、评论、在线状态与游标；正文保存使用版本冲突保护。没有 CRDT/OT 字符级实时合并；并发改同一段落仍需作者解决冲突。
- 支持画布、情节/时间/人物弧、资料库、来源 Wiki、隔离沙盘、作品分支与历史恢复。沙盘是带参数和固定种子的规则模拟，不是能证明真实人物心理或自动预测文学质量的世界模型；分支合并仍由作者选取和采用内容。
- 支持版本化 Prompt、受限 Agent 工具权限、DAG 工作流与最多 50 章生产任务。依赖、人工门、条件和预算会持久化；它们是小说创作专用编排，不执行任意脚本或 shell，也不等于通用 Temporal 平台。
- 自动生产生成候选和审稿产物，不默认替换正文、采用定稿或确认世界事实。多候选和重写仍需作者选择；记忆审核可能成为批量任务的人工检查点。

## 模型、工具与费用

- 支持网页配置多个Provider、发现模型、选默认及按任务路由，Chat Completions / Responses及原生Ollama。页面密钥以AES-GCM加密入库，本机主密钥独立保存，环境变量引用继续兼容。没有自动供应商故障转移或跨服务账单幂等保证。配置接口能连通不代表该模型支持所有JSON Schema、采样参数或流式事件。
- 创作伙伴由Pi执行多轮对话和工具调用，Go逐次审核权限、来源、预算并持久化用量。对话压缩保留近期轮次和来源指针，但摘要仍可能遗漏内容；不会据此写入已确认故事事实。网页资料、正文和用户对话属于不同来源，工具结果只是受限资料，不能覆盖系统权限。
- Responses 设置 `store:false`；服务商自身保留策略由服务商决定。作者选择的模型上下文、Embedding/Rerank 文本和 MCP 参数会发送至对应配置服务。
- MCP 为真实 Streamable HTTP JSON-RPC 客户端及服务端，当前明确支持 2025-03-26、2025-06-18、2025-11-25 版本。无 stdio 任意进程启动、OAuth 交互授权、远端采样、长期通知订阅或所有未来协议扩展。外部连接要求 HTTPS 和公网地址，显式本机回环可用 HTTP；重定向禁用，连接时重新校验地址。
- 外部 MCP 工具须同时满足配置 allowlist、Agent 精确权限和远端只读声明；工具注解是服务方声明，不能证明第三方实现无副作用。调用参数只记录哈希；模型任务冻结真实返回资料。同一意图并发/重放复用持久结果；中断后不自动重复调用。
- 原生模型增量按首次立即、随后时间/字节阈值批量持久化并 SSE 重放。服务若返回完整 JSON，只在响应完成时显示完整结果；不伪造打字增量。中断的部分输出可查看，不代表完整候选。
- 结构化输出受封闭 Schema、实体、源版本和逐字证据校验；可控格式修复只处理 BOM、代码围栏或尾逗号，保留原始结果并标记修复。语义错误不自动补全，不能把格式通过解释为事实正确。
- 用量/费用按每次调用保留，未知不会计成零；不同币种不直接相加。默认模型价格可由服务端环境配置，数据库 Provider 可在管理界面配置币种和输入/输出每百万 Token 单价；排队时冻结价格快照，费用为估算而非服务商账单。另一个 Provider 不会仅因模型同名而继承默认接口价格。
- 预算按请求字节估算 Token 并保留输出上限，不能保证精确等于分词或实际账单。明确金额预算遇到未知历史费用/未定价路由会阻止继续发送；Token 上限不等于绝对金额上限。封面/TTS 等媒体接口费用当前仍可能未知，不由文本预算估算伪造价格。

## 叙事状态、检索与质量

- 事实记忆覆盖位置、伤势、归属、角色知识/误信与伏笔。复杂人物心理、自动遗忘、现实物理和完整因果时间演算不会自动成为确定事实；`storyTime` 未知保持为空。
- 默认关键词/中文二字词/实体召回，另支持真实 HTTP Embedding、Go 余弦评分、关键词向量融合和可选真实 Rerank，不要求安装 pgvector。向量存在 JSONB，当前实现面向单实例作品规模，尚无百万片段压力测试或专用 ANN 索引。
- 向量模型、维度和来源哈希会记录；模型改变需显式重建索引。硬过滤仍先检查作品、活动来源、章节边界与角色知识；不能用更高相似度绕过边界。角色检索刻意不直接投影旁白原段，避免同段秘密泄漏。
- 当前 60 问关键词基线中开发集 Recall@10 为 91.43%、保留集为 93.33%，仍有 4 项同义表达失败。这是受控样例，不能推导任意题材或长篇召回率；真实向量服务已用契约测试验证接法，尚未宣称在该保留集提升。见 [检索评估](../../evaluation/retrieval-baseline.md)。
- 来源压缩是带 source IDs/hash 的派生摘要；使用前重新验证版本和章节边界，不能把摘要本身当作原证据。摘要有效也不证明覆盖全部原文信息。
- 修改旧定稿、删除/重排章节会保守失效下游状态并提示复核；重建仍按章审核，不自动改写后文。复杂倒叙、平行时间线、旅行时长与事实有效区间需作者解释。
- 文学节奏、作者声音、生成质量及节约修改时间的正式作者试用按用户要求后置。工程测试、三章示例、多候选或规则沙盘都不证明长篇文学质量，更不证明每部作品达到“完美”。

## 调研、媒体与出版

- 网络调研保留 URL、抓取时间、资料内容及引用，网页仍可能过时、受版权保护或不可靠；重合检测给出文本重叠线索，不是抄袭/原创性的法律结论。客户端渲染、登录、验证码或付费网页可能无法抓取。
- 封面和 TTS 通过配置的真实 HTTP 适配器生成，离线默认不伪造媒体成功；未配置或服务不支持时返回明确失败。尚未对所有厂商媒体格式、配额、异步恢复协议和账单进行实测。
- DOCX、EPUB、PDF、HTML 可导出，PDF 带中文字体；复杂富文本排版、注释脚注、印刷出版规范和每个阅读器兼容性仍需针对最终作品检查。

## 恢复与部署

- 页面断开只停止订阅。取消/暂停是持久请求，已发送调用可能先完成；远端实际终止及计费不由本应用保证。恢复重新检查正文、章纲、Studio 文档和叙事状态基线，过期任务不得直接续跑。
- 服务可能已执行而本地未得到结果时进入 `NeedsReconciliation`；租约和检查点保护数据库副作用，但不宣称跨模型/MCP/媒体服务恰好一次。需要人工核对后创建新意图，普通重试不会重发未知调用。
- 本机验证使用 Windows PostgreSQL 18.6 与独立测试 schema。提供 Dockerfile/Compose 和独立 API/Worker，但本机未安装 Docker，容器构建启动尚未实跑；回环开发 trust 不是远程部署配置。
- 单作品包包含正文、叙事来源和 Studio 数据；不导出密钥、登录会话或可执行任务。完整实例账、配置、任务和媒体应由数据库及资产备份恢复，不能用作品包替代全实例备份。
- 迁移显式运行。项目原始代码按GPL-3.0-only开放，桌面签名和外部发行验证仍需单独进行。依赖许可证见 [依赖清单](../licenses.md)，参考功能映射见 [优势追踪](reference-advantages.md)。


## 写作 Skill

- 每作品50个保存、最多6个启用，建议任务只启用1–3个互补指南；规则冲突由作者本轮意图/作品设定优先，不能用机械禁词代替审美判断。
- 支持可读文本资料，不执行导入Skill的脚本、第三方Agent或CLI。跨Skill依赖需分别导入，无法随包使用的依赖会显示提示。
- Copilot渐进读取完整规则与引用；原有单次任务完整主规则最多6000字，引用只列目录。超过限制明确拒绝，并建议精简或用Copilot；不静默丢弃规则。
- GitHub固定提交仅核验导入来源，不能证明上游建议正确。服务重启后过往未保存的preview签名失效，重新预览可恢复现场核验标记；本地编辑/导出的来源按声明处理。
- 文学效果、修改时间及长期声音保持继续后置；工程测试并不证明作者理想文风已达到。


## 作者记忆（当前源码）

- 当前用于章节与全书Copilot、适用的单次创作任务、批量和多候选；事实审稿/提取和来源分析排除个人偏好。私人输入独立保存，生成产物仍按作品权限共享。
- 确定性相关性选择最多6条/1600字符，未置顶对话要点需要词语匹配；没有跨语言或任意语义同义召回承诺。
- 只自动提议明确作者偏好，未确认内容不长期生效；模型工具的摘要内容仍需要作者核对。
- 忘记删除长期条目，退出旧活动上下文；原对话、冻结轮次、生成稿件及已有备份另行保留。它不是从所有历史副本中物理抹除。
- 记忆用于可修正的上下文个性化，不是在线训练模型，也不保证模型始终遵循或小说质量自动提升。
