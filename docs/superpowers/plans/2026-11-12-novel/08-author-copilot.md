# 作者流程与 Pi Copilot

日期：2026-11-13。用户授权持续完成Pi接入与作者体验优化，并明确要求书籍规划优先、页面自定义AI供应商。

状态：本轮功能工程已实现，专项PG/HTTP/真实Pi回归通过；最终全量、浏览器及便携交付结果在[系统验收](../../../release/acceptance.md)登记。文学质量、修改计时、A/B/C长篇增益与Docker实跑不在此标为完成。

## 作者路径

登录→书房→新建书籍/选择作品→全书规划与设定→卷章安排→正文写作。书房、书籍概览和写作工作台是不同入口，作者不必先创建章节才能讨论整本书。全局AI配置在书房就可打开。

- [x] 书房独立入口、作品搜索、新书向导、创作基础与目标填写，返回作品时可继续原章节写作。
- [x] 书籍概览集中维护创作基础、人物/世界设定、全书计划与卷章；尚无章节可开启book范围Copilot讨论。
- [x] 全书方案保存为独立book-plan-proposal，作者明确采用后更新plotPlan；不自动建假章或写正文，现有结构化设定保持。
- [x] 章节连续对话、工具执行过程、真实增量、可中断、刷新恢复、候选/Diff和显式采用。

## 职责

Pi1.5.2 Agent Core/AI负责多轮模型与工具循环、真实增量、中断与上下文整理；Go/PostgreSQL负责私有会话、逐次attempt、角色/版本/租约、预算、证据和作者采用。Node不能直接访问数据库、shell或正文文件，只能调用授权小说工具。修改产物先保存为候选。

上下文由稳定指令、当前来源快照、作者选段、设定索引、按需工具结果及派生讨论摘要构成。版本变化退出旧助手/工具/摘要；压缩保留最近完整轮次并持久延续压缩后的上下文，原始事件档案保留。工具结果中的资料不能重定义权限。

- [x] 章节九个领域工具、书籍四个规划工具按scope隔离；chapter提供read_selection/read_blueprint完整源续读，book提供brief字段/目录/设定分页与确认事实检索。
- [x] 启动投影、UI制品反馈和设定索引限长；完整选择锚点、原文及Diff保留在Go/数据库，selectionHash标识当前范围。
- [x] 老工具结果清理、版本变化重建、显式压缩、长对话自动压缩及同一请求多工具交换压缩；保留最新完整call/result和原作者要求。
- [x] 每次generation/compaction由Go先授权attempt/预算；失败、取消、未知结果留账；Go阻断未知前序后自动续调，失效来源与越权候选拒绝。
- [x] 私有会话与候选所有者核验、当前成员权限、冻结正文/Studio/确认记忆/目录基线、SSE游标回放和OpenAPI契约。

完整工具、字段和人物知识语义见[上下文契约](../../../development/copilot-context.md)。研究/MCP、画布、Production等独立高级入口已经实现；本轮没有声称将全部功能都作为聊天工具开放。

## 页面配置

管理员可在页面填写供应商名称、协议、地址、模型与密钥；密钥只写入加密存储，读取只显示是否配置。原环境变量配置继续兼容。本地密钥文件独立保存，完整恢复需数据库与对应密钥；桌面使用其用户数据目录，容器API/Worker共享持久卷。

- [x] 书房即可打开AI供应商配置，支持Responses/Chat/Ollama、免密连接、模型发现/手填、价格和默认连接。
- [x] 凭据write-only、AES-GCM密文、环境变量兼容、旧任务不可变连接版本；地址变化需新凭据，普通成员不能管理全局连接。
- [x] 单独master key恢复材料、API/Worker解析一致、桌面独立密钥目录及共享容器密钥卷配置。

接口与凭据恢复边界见[页面供应商配置](../../../development/provider-settings.md)。
