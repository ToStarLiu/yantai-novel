# 页面 AI 供应商配置

日期：2026-11-13。供应商连接设置是实例管理员功能，不需要先进入某本书。普通项目成员不能读取或修改全局连接配置。

## 页面与接口

`GET /api/provider-settings` 返回已保存连接、当前默认连接及凭据状态。当前环境变量连接作为可复制的起点展示模型、地址与协议，密钥不返回。页面保存使用 `POST /api/provider-settings`，输入字段为名称、协议（`chat` / `responses` / `ollama`）、Base URL、模型、默认/启用、任务路由、可选价格与币种。`apiKey` 是只写字段；普通用户无需配置环境变量名。

编辑时携带原 `id`：未填写新密钥则复用原凭据，另存不可变连接版本，已排队任务仍绑定原模型和凭据。迁移 20 的 `superseded_by` 将旧版本移出当前列表与新任务路由；旧版本仍可按冻结 ID 执行，不能再次编辑或设为默认。切换 Base URL 时必须重新输入密钥和敏感请求头，即使显式带回旧环境引用也不能绕过此检查。清除密钥使用 `clearAPIKey:true`，需要明确选择 `noAuth:true` 或使用免密本地 Ollama。仅将输入框留空不会清除旧密钥。

`POST /api/provider-settings/discover` 接收相同连接字段，可在尚未保存、尚未选择模型时调用。它只请求兼容接口的 `/models` 或 Ollama 的 `/api/tags`，返回模型 ID/name、状态码和简短连接结果；不创建配置、不调用内容生成、不回显供应商原始错误。无法列出模型的供应商仍可手动填写模型名。`PUT /api/provider-settings/{id}/default` 设置默认连接，停用连接不能成为默认。`active` 与 `/api/config` 都优先显示 Copilot 专属路由，再使用启用的默认连接与环境配置。

## 密钥保存

API 密钥和敏感请求头使用 AES-256-GCM 加密后存入 `wb_provider_secrets`。随机 nonce 与连接地址、凭据 ID 共同认证；配置仅保存内部引用，正常 GET 只返回 `hasKey` / `credentialSource` 和敏感请求头名称。旧环境变量引用仍可使用，不把环境变量值返回页面。

主密钥默认位于 `.local/provider-master.key`，可以通过 `PROVIDER_MASTER_KEY_PATH` 指定实例数据目录中的文件。该文件是首次存储凭据时创建的随机 32 字节文件；读取旧凭据时若文件缺失，服务明确报错，不悄悄生成替代密钥。数据库备份包含密文，恢复到另一实例还需要原主密钥文件。桌面包和源代码不应携带用户的主密钥文件。

生成与 Pi harness 使用同一凭据解析入口；持久任务快照保留 Provider ID 与价格政策，不保存明文密钥。明确免密连接不发送 Authorization 请求头；默认 API 连接仍要求有效凭据。HTTP 重定向禁止转发凭据。

## 验证

真实 PostgreSQL 与本地 HTTP 契约测试覆盖：密文不含原文、GET 不回显、敏感请求头解密、实际兼容生成与 Pi 配置解析、编辑复用和旧版本保持、地址变更拒绝隐式复用、清除凭据、丢失主密钥/密文篡改、免密 Authorization 省略、模型发现不生成不落配置、管理员边界、并发默认唯一与实际模型标签。

2026-11-13 本地复测：9 个 workbench 供应商测试与 2 个 HTTP 测试通过，LLM 全包 21 个测试通过。另执行 schema 20 独立数据库的真实转储恢复演练，按回执的 `restoredProviderKeyPath` 解密恢复后的两代配置，并通过 2 次本地 HTTP 验证 API 密钥和敏感请求头。凭据为虚构 fixture，真实供应商调用为 0。回执与 SHA 核对结果见 [备份恢复记录](../../deploy/backup-restore.md)。

这些测试验证软件契约，不证明任意供应商服务始终在线或支持全部模型功能。供应商可以拒绝目录查询或使用不同协议，页面会保留明确反馈并允许手动填写模型。
