# 作者工作流与交互收敛

日期：2026-11-14。目标是让作者打开一本书后，能直接回答“写到哪里、有什么待处理、下一步做什么”，减少编辑正文、讨论和查看修改之间的重复导航。

## 进入一本书

书房的书卡打开“作品概览”，不直接进入正文，也不默认展开整套创作工具。作品首页只有三个主入口：

| 入口 | 内容 |
| --- | --- |
| 作品概览 | 保存进度、继续写作、最多三条待处理事项 |
| 设定与规划 | 内部切换全书规划、人物、世界与规则、文风与写法 |
| 卷章目录 | 章节状态、打开章节、添加下一章 |

写作 Skills 已纳入“文风与写法”的管理入口，也可从“更多”独立打开。全书创作伙伴默认收起，点击“和 AI 讨论”后展开并聚焦输入框；首次展开后，收起和切换本书页面保留组件及未发送内容。刷新后需重新展开，离开这本书的首页不承诺保存尚未发送的对话草稿；已发送对话由既有持久会话保存。

## 概览只显示有来源的进度

进度来自现有作品详情中的章节记录，不生成全书字数、编辑时长、完成百分比或推测的创作质量：

- 有效章节：属于本书且未删除的章节，按章节顺序排列。
- 已保存正文：作品详情返回的只读 hasText 标记为 true，即当前正文版本的纯文本去除首尾空白后不为空。新建章节会有空白初始版本，因此不能只凭版本 ID 计入。旧响应未提供标记时，只能根据已加载的当前正文纯文本判断；没有正文内容就不计入，不推测。它不评判内容是否完成。
- 当前稿已定稿：当前正文版本 ID 非空，且定稿版本与当前版本相同。定稿后又修改的章不计入此项。
- 待复核：章节上已有的 needsReview 标记。没有标记不代表已经通过全面审稿，也不保证没有情节矛盾。

“继续写作”依次选择当前浏览器里本账户、本书最近打开的有效章节、最后一章有正文内容的章节、第一章。新准备的空章节也能成为最近位置；已删除或属于其他书的旧位置被忽略。没有章节时，主行动“准备第一章”进入卷章创建表单，由作者输入后创建。

最近位置同时保留书房通用键与按书的键，后者避免写了另一本书后忘记前一本的位置。它是当前浏览器的本地偏好；清理浏览器数据、换设备或换浏览器会回到章节记录的后备选择。没有该偏好时，最后有正文内容的章节只是可用后备，不声称它就是作者最后编辑的章节。

## 待处理事项与直达

概览最多显示三条有明确来源的事项：

- 项目为 RebuildRequired 时，从本书 /rebuild 返回的 chapterIds 读取待重建队列，定位队列中最早的有效定稿章，再直达助手的故事记忆页面。
- 项目为 MemoryPending 时，从本书 /state 返回的 pendingChapterIds 定位最早的有效定稿章，再直达故事记忆页面。
- 章节已有待复核标记时，打开对应章节的正文。
- 尚无章节、且成功读到的全书简报没有核心冲突或故事方案时，提供故事方向入口。它是可选的规划提醒，不阻止作者直接准备第一章。

定位记忆事项时，队列响应的 projectId 与 epoch 必须匹配当前作品；目标章还须属于本书、未删除并有定稿版本。它不使用“继续写作”的最近章节作为代替。读取中禁用该事项按钮；读取失败或队列已变化时，显示重试或刷新提示，重新获取队列与作品详情后再定位。

同一时刻只显示前三项；卷章目录继续显示各章的真实复核状态。记忆页沿用现有全书提案与重建操作，不会因为点击提醒就自动确认事实、重建或调用模型。

## 从正文到讨论与改稿

写作页常用导航保留概览、正文目录和写法。全局配置、作者记忆、导入导出和工作室等入口集中在“更多”；高级创作能力仍可从工具或快捷操作打开。

右侧创作伙伴分为“对话、本章资料、记录”。对话是默认入口，章纲、设定、故事记忆和检索收在“本章资料”内部；选段操作先填入对话草稿，由作者确认发送。单次写作任务放在可展开的“写作工具”内。

候选在原对话中继续展示比较与采用；单次任务候选可以带回创作伙伴继续打磨。引用上一稿、选段修订、与上一稿或原稿比较、逐段采用仍遵循[连续改稿契约](writing-flow.md)。这轮收敛没有新增自动采用或自动执行下一步。

## 未保存内容与导航

- 作品内切换页面保留全书规划的编辑状态；已打开的文风与写法保持挂载，切换后回来继续编辑。
- 正在编辑人物或世界设定时，切换分类或放弃当前设定会在存在实际修改时确认。
- 离开作品页面、返回书房、进入正文或退出登录之前，规划、设定、文风和非空的章节标题表单受导航保护；浏览器刷新也有离开提示。没有实际修改时不应要求确认。
- 全书规划还有未保存修改时，提交新章节会先返回规划页面，提示保存或放弃修改，保留章节标题，不先创建章节。其他已挂载页面（包括收起的文风编辑）也在创建前统一检查：取消离开不会创建章节。正在提交的章节标题不被当作即将丢弃的草稿重复询问；通过检查并成功创建后，跳转沿用这次确认，不在创建后再次询问。
- 从正文跳转前先完成当前正文保存。保存失败或版本冲突时保留本机缓冲，不切换目标。只有导航成功后才应用“文风与写法”或“故事记忆”等目标页面，取消离开不会暗中改变当前页。
- 新增章节表单仍由作者显式提交；仅输入标题不等于已经创建章节。默认卷名不被当作未保存标题，最近位置、面板宽度和排版偏好不替代服务器正文版本。

数据库、权限和模型运行契约保持现有实现。本轮没有新增迁移或付费模型质量评测。工程回归和文学效果评估分别记录；当前源码更新不代表已有 v0.4.0 桌面下载包同步更新。
