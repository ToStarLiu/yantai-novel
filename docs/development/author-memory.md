# 作者记忆与长期协作

日期：2026-11-13。适用于当前源码工作区；GitHub v0.4.0 发行包不包含本次新增功能。

## 从作者的一次创作说起

第一次使用，先在书房规划作品；无需填写一份很长的个人档案。顶栏的“作者记忆”随时可打开，进入某本书后还可以记录只用于这本书的偏好。写作工作台左侧也有入口，快捷操作可以搜索“作者记忆”。

- 常用写法：记录“叙述克制，用动作承载情绪”，类别选择“文风与表达”。可以放入一小段自己的样例，单条最多1200字。
- 合作方式：记录“先给两个方向，我选定后再展开”，类别选择“合作习惯”。
- 对话中的想法：在自己的消息下点击“记住这句话”，修改标题、内容、范围并保存。原话作为来源保留，记忆内容可以精炼。
- 明确表达偏好时，助手可以提出待确认卡片；可直接记住、先修改或不记住。未确认条目不会作为长期偏好加载。
- 改写候选旁的“更含蓄 / 少解释 / 节奏更紧 / 保留原声”把具体修改要求放进输入框。作者可以补充后发送；这次反馈不会自动成为永久偏好。

每轮作者消息下可以展开“本轮已加载…条作者记忆”，查看这一轮实际选择的条目和版本。它表示已送入本轮上下文，不表示模型必然遵循所有要求。当前偏好列表与历史轮次快照分开显示。

## 三种记忆各司其职

| 内容 | 所属与范围 | 使用方式 |
| --- | --- | --- |
| 故事事实 | 作品级，带正文证据与人物知识边界 | 叙事检索、审核与确认；不从个人偏好升级为事实 |
| 作者记忆 | 当前账号私有；作者通用或指定作品 | 文风、创作偏好、合作习惯、对话记忆；跨会话参考 |
| 对话工作摘要 | 私有会话内派生记录 | 缩短活跃上下文，保留本轮目标、决定、未完成事项与来源 |

写作 Skills 提供可复用的创作方法；作者记忆描述这个作者的默认偏好。当前请求优先于长期默认偏好，作品事实和人物知识不能因偏好被修改。二者都不能授予工具权限。

## 什么时候记住，什么时候忘记

主动填写并保存的条目视为作者明确确认，可以立即启用。助手工具只产生 pending，后端验证 sourceQuote 必须逐字出自这个作者本轮输入，不接受模型回复、外部资料或小说台词作为作者意愿证据。保守的本地识别只对直接表达的稳定写作偏好生成建议，不额外发起一个收费提取请求；普通对话不会每句话都自动写入记忆。明确要求记住的其他对话要点可由受限模型工具提议，或者由作者手动记录。

管理面板可搜索、分类、编辑、置顶、暂时停用、重新启用、拒绝建议和忘记。忘记会删除长期记忆条目的正文；审计只留 ID、动作和内容哈希。原始聊天、当时冻结的私有轮次输入及已生成稿件仍保留，它不意味着删除所有历史档案。导出的是自己的可移植条目，不包含原始来源会话ID和引句；导入先预览，确认后原子保存，重复内容跳过。

有两个全局开关：“在创作对话中使用记忆”和“让助手提出值得记住的内容”。暂停使用保留条目。输入区的“本轮不使用记忆”同时停止本轮加载和提议，成功发送后复位；切换使用状态或记忆基线变化时，旧活动上下文不继续重放私人偏好，页面历史仍可查看。想完整删除历史档案时需要另行管理原对话和备份。

## 上下文与版本

Go按当前账号、作品和任务从 active 条目选择最多6条，标题与正文合计最多1600个Unicode字符。优先置顶、本书要求与查询相关项；未置顶的对话记忆必须有文本相关性。中文二字词和Latin词匹配是确定性召回，不声称具备任意语义同义召回。

启动快照只有有界目录和短预览，完整所选规则经 read_author_memory 按 memoryId/offset/maxChars 读取。本轮私有输入冻结完整选中记忆；候选保存、模型授权、后续工具和采用时再次校验当前基线。修改、启停、忘记或使用开关使旧基线失效。新增 pending 建议不改变有效上下文版本，避免当前生成自我失效。

近期历史与摘要中的记忆也必须遵守同一边界。记忆变化、忽略或关闭时退出旧用户消息、工具结果、回答和摘要的模型重放，防止从原聊天恢复已忘记的偏好；仅正文等普通来源变更仍可保留旧作者意图，要求重新读当前来源。压缩保留具体文风约束与记忆来源指针，并明确它不是故事事实。

## 私有数据

所有读写按当前账号隔离，管理员不能通过作者接口枚举或修改其他人的记忆。指定作品只限制适用范围，不把条目分享给作品成员。共享候选仅存 ownerId/version/hash 有效性标记，不存作者记忆正文；私有会话保存本轮输入与实际工具结果。作品包不导出作者记忆或私有对话；完整实例备份包含这些数据，须按私有数据保存。

所选记忆会发送给作者配置的模型服务，如同对话输入；本功能不改变服务商自己的保留策略。导入资料和记忆只作文本，不执行脚本。凭据样式会被后端拒绝，不应把密钥保存为作者记忆。

当前个性化接入章节和全书 Copilot，以及起草、修订、选段改写、规划、批量和多候选等创作任务。每次任务可关闭，私有快照单独保存；事实审稿、提取和来源分析仍排除个人偏好。具体任务范围与持续改稿操作见[写作流程](writing-flow.md)。
