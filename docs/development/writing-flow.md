# 从作者写法到连续改稿

日期：2026-11-13。对应当前源码工作区；GitHub v0.4.0 下载包保持发行时的内容。

## 作者的操作路径

1. 在作品规划打开“文风与写法”。同一页查看本书文风、节奏、需要避免的写法、自己的私人偏好、文字样例及启用的 Skills。
2. 本书写法随作品共享；作者记忆只对当前账号可见。自己的样例可保存为本书私人文风记忆，先写简短样例，再说明想保留什么。
3. 发起起草、章纲、选段改写或批量制作前，选择是否使用作者记忆。完成后展开“本任务的作者记忆”，查看实际冻结的条目与版本。
4. 在候选中点击“继续打磨这稿”或具体反馈。输入框上方出现候选引用，可移除；编辑消息后由作者发送。
5. 也可选中候选中的一段，点击“只打磨这段”。改稿保留父候选的其他内容；会产生新候选，正文保持原样。
6. 选择“与上一稿比较”查看变化；选择“查看 Diff”以当前保存原稿为基准逐段采用。只有明确采用才创建正文版本。

文风页切换书内标签保留编辑草稿。返回书房、切书、进入写作或退出登录前，未保存修改需要明确决定是否放弃。其他窗口更新规划时，旧编辑保持草稿并阻止覆盖，可显式载入最新版本。

## 哪些任务使用作者记忆

| 任务 | 使用方式 |
| --- | --- |
| 章节起草、定向修订、选段改写 | 加载当前创建者已确认的相关文风与偏好 |
| 全书/卷/章规划、画布场景候选 | 参考写法、合作习惯及当前任务相关的对话要点 |
| 翻译、读者反馈、发展编辑、出版文字建议 | 在当前作者要求和作品约束内参考偏好 |
| 一致性审稿、事实提取 | 排除个人偏好，保持逐字证据及故事事实判断独立 |
| 来源分析、作者声音分析、场景交接检查 | 排除已有个人偏好，依据实际原文与约束分析 |
| 自定义 Agent | 除任务适用外，还需要 query-memory 读取权限；没有权限时界面与后端均排除 |
| 批量制作、多候选生成 | 冻结创建者及记忆版本；适用的子任务使用同一作者，证据任务继续排除偏好 |

全局暂停具有优先级，任务开关不能绕过。设置读取失败时，界面选择本次不加载偏好并提供重试。新任务不自动产生长期记忆；仍由对话提议和作者确认流程管理。

章节Copilot通过现有 read_settings(id=book-writing-profile) 分页读取本书文风、节奏和避免事项；启动只给短目录，不把整份写法重复塞入上下文。人物视角模式不加载这份可能包含全知限制的资料；事实和知识边界仍按来源处理。

## 私人请求与共享产物

普通 Run 与请求追踪仍可由作品成员按权限查看，因此不能把作者档案直接写进它们。migration23 增加独立的普通任务、制作和多候选作者上下文表。共享 Run 只保留创建者、是否忽略、记忆版本/哈希和新增上下文字节数；实际所选记忆及增补后的请求在私有表保存。

Worker 从冻结的私有记录恢复创建者身份，在提交、派发、后续批量步骤、重试/恢复及完成处复核权限与版本。内部无身份任务不借用环境管理员记忆。原作者被停用或移出作品会阻止调用；其他协作者不能接管带私人上下文的任务重试或制作流程。

GET /api/runs/{id}/author-context 仅返回当前作者自己的快照，并要求仍能访问作品。管理员没有读取其他作者档案的例外。current 表示作者记忆版本是否有效，作品输入失效另看 Run.stale；缺少私人记录的旧任务和 Copilot 制品返回404。界面按需读取，不把正文夹带在公开列表里。

所有实际增加的 UTF-8 字节都计入提交及派发预算。使用私人偏好的结果不读写共享缓存，避免跨作者复用。共享请求、尝试快照、Trace、指标和作品包不含私人输入。作者生成的候选、反馈和采用后的作品仍按作品权限共享；不能保证模型永不复述收到的资料。

完整实例备份会包含新的私有表和旧聊天；它应按私人材料保存。作品JSON包不是实例备份，不携带作者私人快照。

## 候选的来源链

CopilotTurnRequest.candidateRunId 明确绑定一份候选；candidateSelection 是其中唯一匹配的原样选段。不能与正文 selection 混用，不能用于全书scope或压缩请求。

普通单次选段改写只有局部输出；绑定到连续改稿时，Go先在冻结原稿上还原为整章候选，保留未选段，原任务输出不变。Go冻结候选ID、原稿Revision、全文哈希、父版和长度；启动只给短来源指针，不重复候选全文。仅绑定时开放 read_revision_candidate，按 offset/maxChars 逐字分页读取正文或候选选段。不同作者、不同章节、未完成/取消、已采用或过期来源不能作为当前改稿对象。

create_revision_candidate 创建新的独立 Run，input.candidateRunId 保存父版；sourceRevisionId 仍指保存原稿。选段替换由Go在冻结父版全文上执行，不使用模型字符偏移，保留其他父版修改。候选链、写法和记忆变化都继续受权限、预算、来源与采用事务保护。

show_diff.compareTo=parent 返回上一稿的真实差异，只供审阅。保存选中的修订始终从原稿 Diff 生成；不能把父版与子版的差异直接套到原稿上。采用请求失败时界面保持“尚未采用”，不把409误报为成功。

## 验证

自动测试验证权限、版本、来源、分页、字节预算、私有记录和界面交互。实际模型文学效果仍需作者用自己的章节评估；本轮使用独立 fake Provider 验收系统行为，不以演示文字评价写作质量。执行结果见[系统验收](../release/acceptance.md)。
