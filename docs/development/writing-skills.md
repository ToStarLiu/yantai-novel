# 作品级写作 Skills

日期：2026-11-13；schema21。入口是书籍概览的“写作 Skills”，章节工作台顶栏也可打开。每本书保存独立配置，读者/审阅者可查看，owner/editor可导入、更改与移除。

## 作者怎么使用

1. 先写下本书想保留的语气与不想出现的写法，最好提供自己拥有使用权的正文样例。
2. 在“导入写作 Skill”选择内置指南、粘贴Markdown、上传SKILL.md/ZIP/JSON资料包，或粘贴GitHub Skill目录/文件链接。
3. 预览正文、引用文件、来源、许可证及兼容性提示。预览不会保存，确认后才加入本书。无需重启服务。
4. 选择用途，例如只用于审稿，或用于起草/改写/创作对话。优先级较高的先发送给模型；冲突最终以本次作者要求和故事来源为准。
5. 新任务冻结所用Skill的ID、版本、内容、引用文件及哈希；Copilot显示本轮采用的指南。原有候选不会被悄悄换规则重算。
6. 可直接编辑主文件并保存新版本；重新导入同名完整资料包可更新引用文件并保留原ID。并发更改返回409，界面保留尚未保存的草稿。可停用或移除，导出Markdown或完整JSON资料包。

建议先用1–3个互补指南，一项关注叙事、一项对白、一项作者文风。每书最多保存50个、同时启用6个；不要把互相矛盾的所有“去AI味”清单全部叠加。硬性禁词/禁标点可能让文字僵硬，应按本书语气修改。

内置五项短中文原创模板：具体叙事与反套路、人物对白与潜台词、有限视角与信息边界、场景欲望/阻力/后果、作者文风样例卡。开源推荐目录包含六个固定提交的条目，详情见[来源调研](../release/writing-skills-research.md)。推荐目录不会自动替作者启用指南，也不会自动追随远端更新。

## 文件与导入边界

主文件为UTF-8 Markdown，可带YAML frontmatter：

```yaml
---
name: my-book-voice
description: 用具体动作和人物不同的说话方式呈现压力
license: MIT
---
# 写作要求
保持本书有限视角；对话保留言外之意；不机械总结人物情绪。
```

name为短名称，description用于工具目录检索；正文才是具体规则。主文件最多100KiB，引用资料最多40份、总计512KiB；ZIP压缩包最多1MiB、100项，且只有一个SKILL.md。允许Markdown、文本、JSON/YAML及许可证/NOTICE。路径穿越、符号链接、特殊文件拒绝；脚本、二进制和包外文件不进入模型可读资料。

GitHub导入固定到具体提交，保留根LICENSE/NOTICE及Skill目录内可读资料。只访问GitHub官方HTTPS地址，不跟随重定向；速率限制或资料超限会明确失败。上游的CLI命令、其他Agent、跨目录依赖和脚本不会自动获得权限。预览会提示未打包的相对引用。第三方指令只是写作参考，不能改变业务授权、模型预算或已确认故事事实。

GitHub现场预览带进程签名；仅经当前API校验的原始预览标记为github-pinned。手改或经JSON/作品包导入的来源元数据按声明处理，不能伪造“已在线核验”。本地编辑会降级核验状态。源码/许可证仍可查看，由作者决定如何使用和再分发。

## 上下文与版本

Copilot采用渐进加载：启动时仅放启用指南目录和有界提示；read_writing_skill分段读取本轮冻结的SKILL.md或引用文件。工具只能读当前作品、本轮启用的资料，不开放文件系统或命令执行。每次响应最多2000字，可用offset续读。多个指南不整包挤入每次请求，仍受活动上下文与预算限制。

原有单次起草/改写/审稿等任务收到按用途筛选的主文件；合计超过6000字会在排队前提示精简或改用Copilot，避免默默截断。单次任务只看到引用文件目录，模型不能假装已读其全文；需要这些资料时使用Copilot。记忆提取不注入文风规则，Skill改变也不让有效的事实提案失效。

增删/修改Skill或启用范围会增加作品的指南版本。对话下一轮重建旧工具/摘要上下文；执行中及作者采用时再次校验版本，旧规则候选不能直接覆盖新要求。正文、章纲、角色知识和记忆来源的原有校验继续生效。原始输入与不可变Skill历史用于复查，派生对话摘要不能代替来源。

## 保存与迁移

migration21增加作品指南计数、当前Skill表与不可变版本表；Go API/Worker共享事务边界。单作品JSON包携带当前Skill、引用文件、启停、用途与优先级，导入创建新ID和v1；旧格式作品包仍可读取。完整数据库备份另外保留历史版本、私有对话及任务快照，恢复时执行队列隔离。

主要实现：internal/workbench/writing_skills*.go、writing_skill_context.go、internal/server/writing_skills.go、web/src/WritingSkills.tsx。HTTP契约见api/openapi.yaml。工程测试验证导入和规则传递，不代表文学质量或“AI检测率”通过。
