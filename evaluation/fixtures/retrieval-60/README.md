# retrieval-60-v1

20章原创受控短文本、60个检索问题，固定40开发/20保留。包含位置、异常事件、伤势、单一铜印归属交替、沈月独知口令、未解伏笔。它是检索工程夹具，不是20章文学长篇质量样本。

- `story.json`：20章正文与五类事实所需的原文证据，稳定章节ID01–20。
- `questions.json`：40个带地点/事件词项的自然问法、4个纯同义改写、6个角色已知口令、10个无答案/角色未知/未来不可见问题。
- `qrels.json`：独立问题ID到稳定源章节ID与逐字证据的对应。
- `split.json`：第一次执行前冻结40/20分组，评分器验证分组一致。

问题不直接复制完整目标句。关键词题仍偏显式，无法证明语义检索；四个同义问题故意保留失召回，用来展示词项检索的边界。未知问题在Recall分母外，单独要求错误返回0，不把空答案算作正确事实。

运行：

```powershell
. ./scripts/dev.ps1 -Action env
go run ./cmd/retrieval-eval --output evaluation/results/retrieval-keyword-<唯一目录>
```

程序在专用随机schema中经真实Service创建作品、定稿、提议/审核/应用状态，使用实际Search入口评分，结束后清理schema；不会写入正常作品或调用模型。每个命中必须匹配实际来源Revision，并验证相应证据。角色知识只返回已获知值，不能为了便于评分把旁白秘密一并返回。
