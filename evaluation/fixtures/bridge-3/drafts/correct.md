# 第三章候选：启箱之前

还是当夜，林川和沈月留在旧桥北岸的废磨坊。雨没有停，木箱仍靠着磨盘。沈月把灯往中央挪了挪，给箱底垫上一块干布。

林川左臂的伤口仍在疼，布带边缘洇着血，他只用右手调整箱子的位置。那唯一的一枚铜印被他从胸前内袋取出，放在自己手边；沈月扶着灯座，没有接过它。

“你只说它与王都有关。”林川看着蜡封，“至于哪一家用的，我还是不知道。”他关于京商凭牌的猜测仍未得到证实。沈月没有补充自己的经历，也没有说出铜印真正的来处。

她先擦去箱盖上的水，又让他记下封蜡纹样。林川答应了，用右手稳住木箱。箱盖依旧紧闭，封蜡也未破开，里面是什么，两人无从判断。

门外石块滚落，两人停下来听了一阵水声。等灯焰稳住，沈月才把薄木片横放在封口前。开箱的准备已经做好，他们却还没有动手。
